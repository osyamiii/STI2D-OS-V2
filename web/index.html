Chargement du portail…

Le portail n'a pas pu démarrer dans ce mode d'ouverture. Ouvre-le par un serveur web :

  1. Sur un ordinateur, dans le dossier STI2D-OS-V2, lance start-server.sh (macOS / Linux) ou start-server.bat (Windows).
  2. Ouvre l'adresse affichée (http://localhost:8000/web/). Sur iPhone ou Android connecté au même Wi-Fi, ouvre l'adresse réseau affichée.

Un aperçu de fichier (app Fichiers d'iOS, aperçu d'un ZIP, pièce jointe) n'exécute ni le JavaScript ni les feuilles de style à côté du fichier.
