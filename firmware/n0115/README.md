# N0115 — STI2D-OS

- Même famille que la N0110 (216 MHz), mêmes logiciels possibles (Epsilon ≥ 23.2, Upsilon récent).
- Build séparé : `make n0115` → `release/n0115/STI2D-OS.nwa` (`-DSTI_TARGET=115`). Le binaire n'est pas présumé identique à celui de la N0110 : il est compilé et vérifié pour sa cible (RAM Epsilon et Upsilon).
- Animations coupées par défaut. Installation et limites : comme la N0110 (voir `../n0110/README.md`).
